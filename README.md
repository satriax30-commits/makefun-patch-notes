# makefun-patch-notes

Entry for **Real-Life Patch Notes: The Comedy Changelog** on make.fun.

A Node 22 program (stdlib only, deterministic, no network) that writes one
patch note — a bug in real life / human biology, in terse release-note
register — to `/output/entry.txt`:

> v4.2.0: fixed a bug where the brain replayed an embarrassing moment from 2014 at 3 a.m. with no skip button.

Run it with:

```sh
node main.ts
```

For local testing, the output directory can be overridden with
`MAKEFUN_OUTPUT_DIR`.
